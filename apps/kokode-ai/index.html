KOKODE for Healthcare

AIを、ここで。

患者データは、ここから出さない。

KOKODEは、機密データをクラウドLLMへ送らず、院内で動かすオンプレミスPrivate AIです。まずはMac Studio 1台から、施設専用のAI環境を始められます。

Private by Design

クラウドではなく、
ここで動く。

カルテ、院内文書、研究データ。外部サービスへ簡単に送れない情報だからこそ、AIをデータのある場所へ置きます。

院内データカルテ・PDF・院内文書・研究資料など
→
KOKODELocal LLM・RAG・AI Agentを院内ハードウェア上で実行
→
Cloud LLM通常運用では患者データを外部LLMへ送信しない構成
Offline by Default

インターネットがなくても、
AIは使える。

通常運用はインターネット接続なしを標準構成に。データ処理は現場のハードウェア上で完結します。

⌁

院内処理

機密データを扱う推論・検索・要約をローカル環境で処理します。

◈

専用AI Agent

院内文書、業務フロー、研究用途に合わせて施設ごとのAI Agentを構築します。

↻

継続アップデート

ハードウェア導入後も、モデル・Agent・セキュリティ更新を継続的に提供します。

KOKODE Update

オフラインでも、
AIは古くならない。

KOKODE本体を常時インターネットへ接続する必要はありません。検証済みのモデル、Agent、セキュリティ更新を、署名済みのオフライン更新パッケージとして定期提供する運用を想定しています。

1
更新通知を受け取る新モデル・機能・セキュリティ更新をご案内。
2
別端末で取得院内AI本体をインターネットへ直接接続せず取得。
3
院内で適用検証済みパッケージを現場の環境へ適用。
