## Backtest Track Record

The published charts currently describe backtest results. The live on-chain
snapshot pipeline, signed history, and public verification chain are pending;
this page does not claim they are operating today.

The intended live pipeline will fetch positions, value assets, compute NAV,
sign snapshots, and publish a verifiable history. Until that pipeline is live,
the runtime pending banner is authoritative.

## Verify

The verification CLI is reserved for the future live snapshot chain:

```bash
pnpm track-record:verify
```

Once the live pipeline is enabled, it will validate schema, signatures,
recomputed metrics, and snapshot content hashes. It is not evidence of a live
public chain today.
