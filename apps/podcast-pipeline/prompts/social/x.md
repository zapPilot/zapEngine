# X

Write short copy that earns attention for the episode share link. The program appends that link automatically, so the copy itself must not contain a URL.

Ideal structure:

1. Hook.
2. Optional one or two sentence explanation.
3. Optional soft CTA.

Avoid generic episode announcements. Prefer roughly 50 to 120 Traditional Chinese characters, but do not pad copy merely to reach a target length.

Use zero to two hashtags. Zero is often best.

Never use announcement-style phrases such as:

- 本期 Podcast 深入探討...
- 今天我們來聊聊...
- 不容錯過...
- 最新一期上線！
- 以下是今天值得關注的四件事情...

Keep CTA understated. Good: `完整脈絡整理在節目裡。` Bad: `立即點擊觀看完整 Podcast！`
