# Zap Pilot design references

[zap-pilot-redesign.html](./zap-pilot-redesign.html) archives the original supplied design prototype. It is a historical reference, not a runtime entry point. The original root copy is preserved.

The implemented design lives in `packages/zap-pilot-story`, with palette, materials, typography and motion owned by `packages/design-tokens/tokens.json`. Product status and recorded numbers remain owned by story facts. Do not copy claims or literal colors from the prototype back into production.

The asset upgrade extends the existing DOM/CSS camera: a hexagonal Bitcoin coin, Ethereum octahedron, stablecoin cylinder with stack grooves, and S&P 500 skyline. The USDC-inspired stable mark represents the collective stablecoin sleeve; it does not establish a specific holding.

Observe plots the two closes recorded in the contract fixture against their respective 200-day averages. Target uses the same recorded weights for model height, badges, ring and bars. Replay comparisons retain exact source values and the backtest disclosure.
