# Zap Pilot story

The product source for capabilities, recorded decisions and pinned replay facts.
Import `@zapengine/zap-pilot-story/facts` from hosts. Evaluation and allocation
orders are explicitly distinct. Contract exports remain generated by the
analytics engine; it writes `src/facts/data/verifiable-strategy.json`.

The rolling backtest datasets remain in landing-page for the daily refresh.
The story replay is regenerated from Git revision `99426e898` and records source
SHA-256 hashes. Verify without changing files:

```bash
pnpm --filter @zapengine/zap-pilot-story pin:replay --check
pnpm turbo run build type-check lint test:coverage deadcode format:check --filter=@zapengine/zap-pilot-story
```
